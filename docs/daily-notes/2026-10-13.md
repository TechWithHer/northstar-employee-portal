## Architecture & Infrastructure Progress

- Continued Northstar V2 Terraform networking implementation.
- Created a dedicated IAM user for Northstar Terraform operations.
- Configured `Northstar-Terraform-Deployment-Role` for role-based infrastructure deployment.
- Created the dedicated AWS CLI profiles `northstar-operator` and `northstar-v2`.
- Continued configuration of the S3 remote Terraform backend.
- Troubleshot IAM role assumption and S3 backend permission issues.

## Issues & Resolutions

- Terraform backend access returned an S3 `403 AccessDenied`.
- Identified that the backend S3 permissions had been attached to the IAM user instead of the assumed Terraform deployment role.
- Moved the required backend permissions to `Northstar-Terraform-Deployment-Role`.
- Temporarily removed the MFA condition from the role trust configuration because the configured passkey could not provide the TOTP required by the CLI workflow.

## Current Status

AWS identity and Terraform backend access are being stabilised before provisioning the Northstar V2 network.
